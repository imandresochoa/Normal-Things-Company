# Normal Things Company

Public letter site for Normal Things Company. The layout matches the Figma desktop and mobile frames. The handwritten logo draws along its vector paths on load.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Stack

- Next.js and TypeScript
- Tailwind CSS
- Satoshi from [Fontshare](https://www.fontshare.com/fonts/satoshi)
- Logo vectors exported from Figma

Desktop: centered letter, 620px text column, 18px type.  
Mobile: same type and logo, content starts from the top with 16px side padding.
